# P2 进度：通用问卷与本土入口

更新：2026-09-22

## 第一波（已合并，main `c7d79200`）

| 车道 | 内容 | 迁移 |
|---|---|---|
| 资源树 API | 建项目（仅租户管理员，建者得 `project_manager`）、建文件夹、按授权分页列出、改名、移动（源父与目标都需 `edit`，防环，按新位置继承授权） | V402 |
| 发布审批 | 提交 / 批准 / 驳回 / 撤回；批准绑定草稿版本，改稿即作废；允许有 `approve-publish` 者自批；发布只发被批准的版本 | V510 |
| 待核对后台核对 | 定时任务逐租户进入 RLS 作用域，同一 `requestId` 原样重发，指数退避，达上限转人工复核 | V520 |

规则见 ADR 0011。集成时补了审批 × 核对的交叉测试，并把测试连接池调小（多个缓存上下文与并行车道曾耗尽 PostgreSQL 连接）。

测试：平台 481 通过；P1 闸门端到端通过（项目已改为经 `POST /v1/projects` 创建）。

## 第一波遗留

- 资源节点不能删除（授权与问卷引用节点）；写接口没有幂等键；移动在极少数重试路径下可能死锁并返回 500。
- 审批人的 `approve-publish` 被收回后，已批准的申请仍有效；待审列表上限 200、无分页。
- 被标记人工复核的核对没有清除接口；核对批次按租户顺序消耗，大积压租户会拖慢后面的租户。
- 已发布问卷仍不能改版再发布（依赖网关支持）。

集成时修复：
- 平台只接受定义 v1，会拒绝 v2 逻辑定义 → 放行 1、2；
- 项目 / 文件夹 id 在答卷与版本接口上返回空列表 → 404；
- 组织免登安全审查：新表补租户外键并改为带 `tenant_id` 的复合外键（外键检查绕过行级安全）；
  组织同步移除成员与手工撤权共用"最后一名所有者"判定（原副本忽略授权过期）；
- 测试环境：`mvn.sh` 不再重建共享 `platform-db`，端到端收尾不再停它；引擎端到端驱动跟随 `SURVEY_TEST_PREFIX`；测试入口脚本补可执行位。

测试：平台 635 通过；网关 379 通过；P1 端到端（含改版再发布）45 项、逻辑端到端 MySQL / PostgreSQL 各 30 项通过。

## 第二波遗留

- **`/v1/identity-bindings` 没有权限判定**（P1 起即如此）：租户内任意成员可创建或按主体查询外部身份绑定。组织免登复用这张表，未造成越权登录（新主体无成员资格），但必须收紧到"管理成员"——列为第三波第一项。
- 组织免登：事件回调、定时 / 分页同步、部门映射、撤销后恢复绑定、`start` 限流（网关层）、停用租户登录拒绝均未做；各开放平台部分接口字段待凭据到位后逐页核对。
- 改版切换时正在作答旧版的人在下一页被截断（无宽限期）；手工清除旧版到期会重新开放且漂移检查不报。
- 逻辑：清值依赖引擎 `deletenonvalues=1`（部署要求）；续答后的清值、计分与随机组（03.3）、日期类型未做。
- 答卷：手工停用再激活引擎问卷时的短暂编号窗口；06.2 导出作业未做。

## 第三波车道：WP-04.1 / 04.2 访问与作答规则（ADR 0016）

定义可带 `policy` 块（契约 survey-access-policy-v1，定义版本不变）。覆盖 R04-01（统一访问密码，
平台 PBKDF2 哈希、明文不落库）、R04-02 部分（邀请码＝参与者 token＋`access_mode=C`）、
R04-03 部分（token／设备／IP 组合限次）、R04-04（时区窗口、作答时长，服务端时钟）、
R04-05 部分（IP 规则；地区为可插拔数据源，无数据按 `regionUnknown` 拒绝或放行）。

| 层 | 内容 |
|---|---|
| 平台 | 草稿保存时 `access.password` → `passwordHash`，时间窗缺时区填 `Asia/Shanghai` |
| 网关 | `pubgw/policy/`：422 校验、本地时刻→UTC（夏令时缺口／重叠拒绝）、原生设置＋LSS `plugin_settings`、激活前回读摘要 |
| 插件 | `MjyRuntimePolicy`：`beforeSurveyPage` 闸门（时间窗→IP→地区→密码→限次→时长），fail closed；`policyStatus` 回读端点 |

测试：网关 448（新增 69）；插件 70（新增 46，MariaDB／PostgreSQL）；平台 644（新增 9）；
真引擎端到端 `run-access-policy.sh` 38 项，MariaDB／PostgreSQL 全过（含"改客户端时间不延期"、
"同一 token 换浏览器不能重新计时"、"解锁只对本 sid 有效"）。

遗留：地区数据集未交付；租户级时区；平台未校验网关回执 `policyDigest`；网关 `add_participants`
总是替换定义里的 token；同一身份两个会话同一瞬间交卷会落两份；密码错误次数只按会话计。
