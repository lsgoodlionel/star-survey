# Wave 6 套餐目录

已合并的独立平台管理员授权是运营权限边界。此切片提供按套餐编码分页的最新已发布版本目录，展示真实能力、额度、导出窗口和发布时间；端点每次要求平台人员授权，未授权或撤权不得保留旧数据。已发布版本不可变，当前租户订阅仍绑定其原版本。

这只是套餐管理的首个只读切片：版本历史、带审计的版本发布、选择版本和租户开通界面仍须继续实现。现有发布接口缺少运营审计，不能直接把页面接到写接口后声称完整；写入应先确定事务内审计、并发版本冲突和失败恢复，再以已验证人员会话、撤权及隔离浏览器旅程验收。完整套餐管理不能因目录通过而标为完成。

定向测试使用隔离数据库和签名人员会话；当前 main 的浏览器夹具仍为旧运营令牌。待 PR #47 人员 guard 浏览器夹具合并后复用，真实人员浏览器和双库在线门禁均须按最终提交核对。
