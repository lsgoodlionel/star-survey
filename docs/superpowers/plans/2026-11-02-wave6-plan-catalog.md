# Wave 6 套餐目录

已合并的独立平台管理员授权是运营权限边界。此切片提供按套餐编码分页的最新已发布版本目录，展示真实能力、额度、导出窗口和发布时间；端点每次要求平台人员授权，未授权或撤权不得保留旧数据。已发布版本不可变，当前租户订阅仍绑定其原版本。

版本历史、发布与开通：运营人员查看不可变历史，选择指定版本并确认租户、所有者、类型与期限；发布使用预期版本和每套餐事务锁，并与追加审计同事务提交，冲突和未知结果要求重新核对。租户开通在同一事务按现有身份锁顺序锁定并复查租户状态，避免关闭并发后仍开通。新目录、版本和发布表单以十进制字符串传递额度，订阅接口保留旧数字字段并新增精确字符串字段；界面不能以不安全的旧数字近似值代替精确额度。

定向测试使用隔离数据库和签名人员会话；正式人员真实浏览器旅程覆盖发布、历史、开通、审计和版本绑定。复用 PR #47 的独立人员 guard 夹具，并以最终提交的双库在线门禁为准；真实生产套餐发布与租户开通不在授权范围。
