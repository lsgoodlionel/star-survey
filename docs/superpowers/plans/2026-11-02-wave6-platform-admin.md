# Wave 6 平台管理员实施计划

平台管理员使用独立 grant；组织登录必须有已验证的 issuer、主体和有效 sid，普通租户角色或无 sid 机器令牌不能提升为平台管理员。外部 IdP 按 ADR 0010/0014 另行配置非对称 issuer、audience 和 JWK，不能复用组织身份命名空间。

人员 grant 写入信任 Platform Service：验签后的 SecurityContext 是唯一 actor/sid 来源，请求只包含目标、动作和原因；运行账号只获得 `platform_admin_change_session` 的 EXECUTE，没有表直接写权限，也没有旧 raw mutation、bootstrap、recovery 的执行权。数据库在一个事务中锁定并复查会话、当前 grant、目标可用性及最后可用管理员，变更和审计一起提交。此模型不声称在主应用 RCE 或运行数据库凭据泄漏后仍能阻止伪造调用：数据库信任应用传递的 actor/sid；参数化 SQL、最小权限和凭据保护仍是必要防线。不得以数据库 owner 处理应用请求。

身份失效会持久使 grant 失效并审计；身份恢复不会自动恢复旧授权。安全撤销不能因最后管理员失效而阻拦；零可用管理员时经独立受控恢复。数据库恢复函数默认无运行账号执行权；当前仅记录数据库 session_user，不能据此认定具体自然人。真实 bootstrap/recovery 需要独立可归因的操作者身份、明确原因与授权，以及部署流程和审计复审。`DeploymentActorAttribution` 是未接入的输入校验草案，不证明登录账户确属某个人，不能替代实际身份管理。

身份写语句在 BEFORE STATEMENT 获取共享授权事务锁，再获取相关行锁；隔离测试覆盖锁阻塞、批量失效和恢复。该全局锁串行化身份写入；若调用方事先持有其他行锁，仍可能死锁。数据库死锁 40P01 或序列化失败 40001 必须回滚整个事务；仅在无外部副作用且确认未提交时有限重试。应用尚未实现自动重试，也未对供应商调用做重试；启用前须审查吞吐和跨模块锁序。

现有生产 setup-probe 使用共享 HMAC 的无 sid platform_operator；它实际调用六类端点：创建租户、发布套餐、租户开通、租户状态、引擎注册和事件密钥读取。下一步独立机器凭据应有专用验签信任、audience、短期有效期和逐方法/路径 scope，并将动态租户/实例绑定到该探针创建的资源；事件密钥读取不能对普通机器开放。先完成隔离 install/probe 回归、切换与回滚，再迁移现有 guard；不能仅按 subject 字符串区分机器。

服务端 capability 不缓存 grant，测试覆盖已验证人员、撤权和旧机器令牌；该能力尚未连接正式导航或现有运营 guard。真实 IdP、机器凭据、bootstrap 操作者、部署、发布和真实授权均另需确认。本切片必须经父任务独立安全审查及 GitHub CI，不可直接视为生产准出。

隔离机器原型使用单独注入的测试密钥、独立 issuer/audience、最长五分钟有效期和六个显式 scope；方法/路径检查对动态租户和实例使用绑定标识，并拒绝人员授权端点。当前这两个原型没有注册为运行组件，不能单独作为授权：创建请求体必须限于探针专用资源，绑定身份必须来自可信令牌及服务端所有权状态，事件密钥范围、重放、密钥轮换以及 setup-probe 逐步骤凭据和安装/回滚测试均未完成。不得因这些隔离测试通过就接入旧 guard 或创建真实凭据。

隔离测试现另覆盖六类调用的精确顺序、方法、固定探针额度，以及仅接受绑定探针编码、套餐版本和实例的创建请求体。生产 setup-probe 仍使用旧令牌；该请求体原型未连接路由，绑定值尚未由服务端持久所有权状态证明，不能作为机器授权的最终实现。

隔离资源归属增量：探针验签结果保留 installation/run/tenant/engine 绑定，路径匹配只使用已解析的凭据；服务端归属检查从租户编码和创建审计、不可变套餐版本与固定额度、活跃引擎和登记审计核对该安装及运行身份。跨安装、跨运行、客户租户、错误套餐／引擎及停用引擎均拒绝。该检查只覆盖最后的完整资源状态，尚未作为逐步骤 handler 接入，也未实现并发创建的幂等重试；创建和审计须同事务，不能以客户端传参替代所有权证明。

bootstrap/recovery 受控运维接口：`platform_admin_bootstrap_attributed` / `platform_admin_recover_attributed` 要求显式执行人标识、原因和追踪号，单事务追加审计并同时记录数据库认证的 `session_user` 与明确标注为“声明”的执行人标识。PUBLIC 与 platform_app 均无执行权。部署 DBA 应在已批准环境中只向经过身份管理的个人运维数据库角色临时授予对应窄函数 EXECUTE、完成后撤销，不能把 owner 凭据交给应用；角色与自然人映射、工单和调用人声明的核对由部署侧身份与审计流程保证。数据库只验证登录角色，不验证声明的自然人；共享 owner 登录不能证明具体执行人，不能据此宣称归因完成。本次未创建或授予任何真实角色。
