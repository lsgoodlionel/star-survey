# Wave 6 平台管理员实施计划

依据 `2026-11-02-platform-administrator-authorization-design.md`，按独立切片推进：

1. 明确人员与现有机器探针的信任边界、数据库授权和 bootstrap，建立失败测试及隔离授权存储与审计；不可授予真实身份。
2. 将服务端能力和人类运营 API 接到逐请求授权；迁移前先完成探针独立机器身份和兼容性测试，保留安装与发布链。
3. 补前端入口、身份切换和失权恢复；针对跨租户、撤权、并发与故障执行隔离测试和 GitHub CI。
4. 父任务独立安全审查数据库迁移、授权、机器兼容与生产准入；真实 IdP、realm、首个管理员和生产配置均须明确授权和验证。

2026-11-02 原型边界：运行数据库账号仅可检查当前授权，不能调用 bootstrap 或授权变更；不提供 HTTP 写入口。直接把应用传入的 actor 参数交给安全定义函数，数据库无法证明其与已验证会话一致，会产生伪造审计及越权风险。人员授权写入机制、目标身份有效性验证、现有机器探针隔离和端到端接入必须先完成设计与独立安全审查。本原型未连接现有运营路由，不能作为已完成角色或生产登录方案。
