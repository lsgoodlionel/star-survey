## 2026-11-02 初步对账

- 租户：`TenantAdminController` 原有创建、按编码/ID读取及状态迁移；目录和独立管理界面此前缺失。本切片仅补只读目录与详情，状态修改仍未接入页面。
- 套餐/成员/组织连接/引擎实例：现有 entitlement、access、org 和 engine 后端模块不能代替完整管理旅程；需逐项核对读写契约与页面，尤其检查跨租户授权、变更审计、撤权。平台模板已有租户模板中心的部分运营操作，尚需检查完整管理旅程。
- 运营身份阻断：`PlatformOperatorGuard` 只认已验签 JWT 的 `platform_operator`，而正式组织登录 `PlatformTokenIssuer` 固定签发空角色；生产手册现仅记录 setup-probe 短时运营令牌。尚未找到正式人员获取该角色并进入独立运营台的已批准路径。须确定生产身份来源、授权及撤销模型并经安全审查，不能使用测试令牌充当正式登录证据。
- Release 工作流已有同一候选四节点原生门禁与 SBOM、签名、证明；最近 PR 只读构建成功不代表候选已通过原生矩阵。未经授权不打 tag、不发布镜像或 Release。
