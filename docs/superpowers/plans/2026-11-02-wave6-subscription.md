# Wave 6：当前租户订阅

现状：开通接口只能由现有平台运营令牌发布套餐版本、按已知代码读取最新版本并为租户开通；尚无套餐目录和租户订阅管理旅程。平台模板和引擎实例已有运营 API，但其人员身份仍依赖待替换的运营授权。不能扩展现有角色声明回退作为新的人类授权机制。

本切片先提供当前租户只读订阅：租户只由已验签会话确定，服务端要求租户级 manage-settings，展示实际绑定的不可变套餐版本、当前订阅状态和期限；不接受目标租户参数、不作套餐变更。验证无令牌、无权限、跨租户参数、无订阅和过期状态；浏览器在隔离租户中验证，双库门禁交 GitHub CI。套餐目录、跨租户订阅变更及运营页面仍需完成独立平台管理员授权后另行实现。

平台管理员下一实现包按依赖推进：
1. 绑定受信身份命名空间与实际资源服务器会话验证，覆盖过期、撤销、身份不匹配和机器令牌；现有隔离测试可继续使用测试身份。
2. 在同一事务中处理授权写入、审计和身份失效，持久化身份授权世代；身份停用、成员移除或身份绑定撤销后，恢复身份不能恢复旧 grant，必须显式重新授予。并发验证最后可用管理员、撤权与身份变更，以及受控恢复。
3. 将写入操作的 actor 限定为验证过的安全上下文；bootstrap 默认关闭，显式配置、记录部署操作者和原因，并避免运行时数据库属主权限。
4. 服务端提供能力并迁移运营页面及 guard；先定义独立机器凭证、audience、最小端点权限并验证 install/probe，移除无约束人员角色回退。全部在隔离环境完成后才考虑运行时启用。

代码和测试不需要真实 IdP 或账户；真实 issuer、audience、信任密钥、部署环境、bootstrap 操作者及机器凭证只在实际部署配置前确定，任何真实授权或部署须另获批准。
