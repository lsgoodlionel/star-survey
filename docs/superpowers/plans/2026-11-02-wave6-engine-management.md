# Wave 6 引擎实例管理

平台人员从租户详情查看该租户的实例，登记时填写实例标识和不含凭据的 HTTP(S) 基础地址；登记只写平台记录，不连接真实引擎。界面使用服务端 capability，明确确认写入，支持 active、draining 与 retired 状态及终态提示；失权或读取失败不得保留旧内容，冲突或未知结果重新读取，不自动重试。历史地址显示时去除用户信息、查询和片段。

登记事务先取得 V952 身份变更全局锁，再锁租户行并复查状态，与并发关闭保持同一顺序；数据库写入与审计同事务。此锁串行化身份状态变更与登记，需关注吞吐，其他调用方不能先持不兼容行锁再取此锁。隔离测试覆盖正式签名人员会话、独立 grant、跨租户路径、终态、撤权、审计及审计失败回滚，并验证关闭先提交时不得留下实例；安装探针调用需回归。

复用 PR #47 的人员 guard 浏览器夹具，在隔离租户登记占位地址、停止接流量、退役、核对审计，再验证撤权拒绝；最终双库 GitHub 门禁和父任务独立审查仍须按最终 head 核对。没有调用真实引擎或创建真实凭据。平台模板补充正式人员 guard 的隔离浏览器旅程：导入、增加版本、指定版本 2 上架、下架、核对操作审计及撤权后 API／页面拒绝；本地隔离 PostgreSQL 和 Chromium 通过，最终双库 CI、生产和 VoiceOver 均另行验收，不据此提升六层为 accepted。
