# 平台管理员身份与授权设计（Wave 6）

状态：用户已选择独立平台管理员角色和独立授权记录；具体生产身份提供方、realm、操作人和部署配置尚待确定。本设计不授权任何真实身份。

## 身份与边界

平台管理员是跨租户控制平面的独立权限，不从 tenant_owner、组织管理员、租户角色或组织组隐式提升。遵循 ADR 0010/0014：当前组织登录采用受信任的已验证租户+主体+有效 sid 及逐请求会话撤销检查，roles 保持空；未来外部 IdP 使用独立受信 issuer、audience 和非对称 JWK 验签，绑定不可混淆的 issuer+subject，不允许只凭客户端提供的名称或未经认证的声明授权。两类身份命名空间不得互相覆盖。未配置/未知 issuer、audience、主体或会话、验证异常均拒绝。无 sid 的现有探针令牌不能作为人员身份。

## 平台授权

独立持久化平台角色授权，唯一主体键包含身份来源及不可变主体标识；记录角色 `platform_admin`、状态、授予人、时间和撤销信息。每个管理请求在服务端检查有效授权和会话；撤销后下一请求生效，无授权或存储异常失败即关闭。授予和撤销与追加审计在同一事务，记录操作人、目标、动作、时间、追踪标识，不记录令牌、密钥或凭据。防止最后管理员误撤销；并发变更序列化。授权存储独立于租户成员角色、租户授权及 RLS 范围；运行账户不应获得可绕过审计的直接写权限。具体数据库权限和迁移须审查并验证。

首次授权只能通过受控部署管理员 bootstrap：要求明确指定已验证且不可变的身份键，默认关闭、显式执行、记录审计、幂等且不得在已有管理员时隐式提升其他人；不能从环境变量或普通租户管理员自动授权。此代码设计不代表对任何真实环境或账户的授权。

## 兼容与接入

服务端提供平台能力快照，前端按服务端能力显示独立运营入口，但接口逐请求判权才是边界；注销、失权、403 和切换身份需清除或隐藏缓存。平台模板运营控制与租户模板权限继续隔离。

现有 `PlatformOperatorGuard` 基于共享 HMAC 的 `platform_operator` 声明，生产 `setup-probe` 使用无 sid 短期机器令牌。新增平台人员授权不能复用这个声明或把探针身份作为人员管理员。迁移须单独定义机器调用的身份、密钥、audience、最小端点范围和过渡/回滚策略，覆盖安装、探针、E2E、API 与生产发布门禁；不能仅按可伪造的 subject 字符串区分人员与机器，也不能在无替代方案时破坏现有生产生命周期。

## 验收

先建立失败测试：同名不同 issuer/租户隔离、无 sid 或无授权拒绝、假租户角色拒绝、有效授权通过、撤销下次请求生效、存储错误失败即关闭、最后管理员与并发保护、bootstrap 限制、授权及撤销审计原子性、前端 capability 和缓存隔离；隔离数据库及 GitHub CI 验证。外部 IdP 的实际配置、真实操作人 bootstrap、生产部署及 Release 需另行授权与环境验收。

## 原型限制与恢复设计待完成

组织身份来源固定为 `org-session-v1`，以租户和主体组合区分；外部 issuer/subject 不得复用该命名空间。当前原型仅按本地记录检查租户在用、成员在职、绑定未撤销和存在启用的对应组织连接，这不证明外部身份服务或凭据可用。审计记录数据库会话用户名和操作原因，但共享数据库账号本身不能归因到具体自然人。

离职、绑定撤销和租户停用必须立即使该人的权限失效，不能为维持管理员数量而继续信任失效人员。如果最后一位人员失效，应失败关闭并进入有明确操作者、原因、身份核验和审计的受控恢复流程；恢复不得自动重启旧授权。身份状态变更与授权变更的串行化、恢复操作的事务边界和并发测试尚待设计实现。运行账号不具备授权写入或 bootstrap 能力，原型不得接入生产运营入口。
